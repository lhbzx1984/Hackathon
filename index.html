MODULE 01

LLM：一个超大号的「下一词预测器」

大语言模型（Large Language Model）的本质出奇地简单：读过几乎整个互联网的文本后， 它学会了一件事——给定前文，预测下一个 token 的概率分布。 写代码、写诗、答题，都是这一件事的重复。下面亲手试试。

下一词预测器LIVE

模型看到的前文：

夜空中的星星非常

也可以直接点击某个候选词，强行「选」它

为什么它能「无所不知」？

预训练：在数万亿 token 的文本上，反复练习「猜下一个词」。为了猜得准，它被迫学会语法、事实、逻辑甚至代码风格。

自回归生成：每次预测出一个 token，就把它拼回输入末尾，再预测下一个——像接龙一样，一个词一个词把答案写出来。

上下文窗口：模型的「工作记忆」，一次能装下的 token 上限（如 128K）。你发给它的一切，都在这个窗口里。

参数量：模型的「脑容量」，从几十亿到上万亿。参数越多，能记住的规律越细腻。

小结：LLM 不检索答案、不查数据库，它只是极其擅长「猜下一个 token」——猜着猜着，答案就成形了。

MODULE 02

温度与采样：模型的「性格旋钮」

模型每次输出的都是概率分布，从分布中抽取哪个词，由采样参数决定。 拖动滑块，观察同一句话的候选词概率如何被重新分配，再连按几次采样感受差异。

参数作用怎么用
temperature调整分布的「陡峭程度」接近 0 稳定刻板；0.7 左右平衡；1.5+ 天马行空
top_p只在累计概率前 P 的词里采样0.9 = 砍掉长尾，防胡言乱语

max_tokens限制最多生成多少 token控制成本与长度
stop遇到指定字符串就停如让模型只输出 JSON

比赛经验：写代码、提取信息用低温度（0–0.3）；起名字、想创意、写文案用高温度（0.8–1.2）。 长尾怪词多时，加一个 top_p = 0.9 兜底。

MODULE 03

Token：模型眼里的文字长什么样

模型不直接读「字」或「词」，它读 token——文本切出来的小块。 经验值：1 个英文单词 ≈ 1.3 token，1 个汉字 ≈ 1～2 token（不同模型分词器不同）。 你的提示词、模型的回答、API 账单，全按 token 计数。输入一句话，看看它被切成什么样。

MODULE 05

Agent 生态：从「会聊天」到「会干活」

裸的 LLM 只会「说」；让它「做」，需要一整套装备。点击卡片查看每个角色的详细分工， 再运行下面的智能体循环模拟器，看看一个任务是如何被自主完成的。

AGENT

智能体

LLM 当大脑、工具当手脚、循环当心脏：给定目标，自主拆解任务、调用工具、根据反馈调整，直到完成。

SKILL

技能

打包好的「能力包」：提示词 + 流程 + 示例，让模型在某类任务上更稳更专业。

MCP

工具协议

连接模型与外部世界的「USB-C」：数据库、搜索、天气、办公套件，通过统一协议挂载给模型。

HARNESS

运行框架

智能体的「发动机舱」：驱动循环、投喂工具结果、管理上下文与安全边界的整套运行时。
